# fox-university-website-clone

A frontend recreation of the Fox University website built using HTML and CSS. This project was created to practise frontend web development, with a focus on website structure, styling, and layout.

## Overview

This project recreates the visual design and layout of the Fox University website using fundamental web development technologies.

It is a frontend-only project. No backend functionality has been implemented.

## Technologies Used

- HTML5
- CSS3

## Features

- University website layout
- Styled navigation and page sections
- CSS-based visual design
  

## Getting Started

To view the project locally:

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project folder.
3. Open the `Home.html` file in your web browser.

Alternatively, download the repository files and open `Home.html` directly in your browser.


## Disclaimer

This project is an independent educational exercise created for frontend development practice. It is not an official Fox University website.
